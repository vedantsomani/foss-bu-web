Fragline: engine provenance, corresponding source and changes
=============================================================

ENGINE (GNU GPL v2 or later, full text in ENGINE-LICENSE.txt)

  websockets-doom.wasm.gz   Crispy Doom 7.2 compiled to WebAssembly, gzip-compressed for download
  websockets-doom.js        Emscripten loader for the binary above

  Corresponding source: the engine/ folder of this project's repository
  (https://github.com/vedantsomani/foss-bu-web). engine/crispy-doom/ is Crispy Doom imported
  unmodified from https://github.com/fabiangreffrath/crispy-doom (commit recorded in
  engine/UPSTREAM.md); every Fragline change is marked [fragline] in the source and listed in
  engine/README.md. engine/build.sh rebuilds both files above.

  Browser networking (net_websockets.c and the related changes) is ported from Cloudflare's
  doom-wasm (https://github.com/cloudflare/doom-wasm, GPL-2.0).

GAME DATA (BSD-style license, FreeDM-COPYING.txt)

  freedm.wad.gz   FreeDM 0.13.0 deathmatch IWAD by the Freedoom contributors, gzip-compressed for
                  download; decompresses to the unmodified release file:
                  sha256 d9adc4d792627e7fc47b09067b15486da724010c71dd12831e1cf8e0755b68ad
  Credits: FreeDM-CREDITS.txt and FreeDM-CREDITS-MUSIC.txt. FreeDM contains no id Software content.

FRAGLINE'S OWN FILES

  fragline.wad    Title screen only (TITLEPIC), generated by tools/make_art.py
  game.js, index.html, style.css, controller.js, sw.js, src/index.mjs, lan_server.py, lab/
  The room relay design follows Cloudflare's multiplayer Doom router (BSD 3-clause license,
  CLOUDFLARE-LICENSE.txt).

No commercial Doom data (doom.wad, doom2.wad) is included or needed.
